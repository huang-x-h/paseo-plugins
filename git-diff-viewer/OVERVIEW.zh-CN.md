# Git 仓库查看器

在 Paseo 内查看工作区关联的 Git 仓库。面板会扫描工作区中的仓库，展示每个仓库的分支、上游跟踪状态、改动数量和最近提交，并可从下拉框切换仓库。

改动页。列出当前比较范围内有差异的文件，显示新增和删除的行数，展开文件即可查看 diff。比较范围有两种：工作区的未提交内容，包含已暂存、未暂存和未跟踪文件；以及上游分支与本地 HEAD 的差异。只有当前分支配置了上游跟踪分支时，才出现上游范围，且该比较基于两个提交快照，不会自动 fetch。每个文件可在差异和全文之间切换。

历史页。浏览任意本地或远程分支的提交历史，查看提交说明及其改动的文件。

使用前提。守护进程所在机器需安装 Git，工作区目录需位于 Git 仓库内。扫描最多向下四层，跳过依赖目录和常见构建目录，不跟随目录符号链接。工作区目录内没有仓库时，插件会列出含仓库的上级目录并等待确认，不会自行扩大范围把无关仓库带进来。

插件只执行只读 Git 命令并读取未跟踪文件，不上传代码、不修改仓库、不切换分支。二进制文件不预览，超过 200KB 或 5000 行的文件只显示开头，超过 200,000 字符的 diff 会被截断。
